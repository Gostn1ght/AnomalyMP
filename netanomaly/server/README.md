# Серверное состояние игроков

`store.py` — компонент серверного хранения, пока без адаптера движка и сетевого API.
Это не завершённая система аккаунтов в игре.

SQLite хранит аккаунты с солёными PBKDF2-хешами паролей. Первый и последующие
аккаунты получают роль player. `LocalConsoleAccounts` предназначен только для
локальной серверной консоли; клиентские команды в этот адаптер направлять нельзя.
Изменения прав записываются в журнал в одной транзакции с изменением роли.

`sessions.py` привязывает транспортный peer к проверенному аккаунту, запрещает
одновременный вход одного аккаунта дважды и проверяет актуальную роль при запросе.
Проверки пока выполняются в тестах компонента, а не в сетевых событиях движка.

Состояние игрока хранится по постоянному ID аккаунта: локация, координаты,
направление, деньги, здоровье, инвентарь с состоянием, боеприпасами и свойствами
предметов, индивидуальные задания. Снимок одиночного мира не принимается.
Проверка revision не позволяет старому снимку затереть новую запись.

Предмет с одним постоянным ID имеет одного владельца. `save_players` фиксирует
инвентари и балансы нескольких аккаунтов вместе; так серверный адаптер сможет
сохранять обмен одной транзакцией. Правила торговли и применение обмена к
игровым объектам всё ещё должен реализовать адаптер движка.

Подключение к движку ещё требуется. Серверный адаптер должен:

- Привязать соединение к ID только после проверки аккаунта; nickname не является ID.
- Собирать инвентарь и остальное состояние из серверной симуляции.
- Сохранять при периодическом checkpoint, выходе и штатном выключении сервера.
- Восстанавливать игрока после входа, не перезагружая мир остальных игроков.
- Проверять роль на сервере при каждой административной операции.
- Вызывать хранилище в потоке владельца соединения SQLite.

Сетевой вход, защита транспорта, применение инвентаря к объектам GAMMA,
генерация заданий и полноценная консоль здесь ещё не реализованы.

Для локальной работы с подготовленной базой есть предварительная текстовая
консоль: `python netanomaly/server/console.py --runtime <gamma-runtime>`.
Команды `register`, `accounts`, `admin` и `unadmin` работают с серверной SQLite.
Это не подключение к игре и не требуемое полноценное графическое окно консоли.

`ticket LOGIN p1|p2` проверяет пароль без его вывода и записывает одноразовый
билет на 5 минут в отдельный appdata клиента. Native auth/roles добавлены в
engine/gamma.patch; этот патч ещё не собран и не проверен игровыми клиентами.
Роли публикуются в appdata/server/account_roles атомарной заменой файлов.
Снятие прав публикует player до фиксации транзакции; выдача admin — после неё.
