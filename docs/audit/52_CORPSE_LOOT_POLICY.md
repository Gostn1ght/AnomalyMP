# 52. Согласование backend очистки трупов (2026-10-07)

Последнее правило владельца имеет приоритет над прежним сохранением лута
corpse→ground: труп удаляется с оставшимся лутом при рестарте и через 40 минут
без игрока рядом. Native runtime уже выполняет это правило (см. запись Claude
2026-10-06 23:30 и live суточный прогон в журнале). Здесь исправлен backend,
который ещё переносил содержимое удаляемого тела на землю.

После разрешённого corpse_cleanup оставшиеся вещи получают kind=DESTROYED.
Это терминальные ledger записи: ID не переиспользуется, сохраняются исходные
quantity/state для аудита. DESTROYED не разрешён как endpoint create/move,
location_state не публикует такие предметы. Содержимое трупа больше не
превращается в автоматически возникшую кучу предметов на земле.

Подобранная игроком вещь остаётся PLAYER; самостоятельные WORLD предметы
и тайники не затрагиваются. Старые вещи, которые ранее уже оказались на
земле, сохраняются: миграции с массовым удалением предметов нет.

Сохранены bounded cleanup партии (64 предмета/4 MiB), их durable continuation,
rollback, проверка writer/fence/version и запрет новых вещей в удалённое тело.
Schema migration не нужна: kind — существующее текстовое поле без перечня
значений в CHECK. Новое terminal значение используется только внутри cleanup.

Проверка: все 241 backend tests локально PASS (50,2 с), включая предмет,
подобранный между партиями, независимый предмет на земле, рестарт, невозможность
восстановить/подобрать DESTROYED ID, инъекцию сбоя в журнал и continuation.
CI [World Backend 37578839647](https://github.com/Gostn1ght/AnomalyMP/actions/runs/37578839647):
все 241 тест PASS на Linux (24,8 с) и Windows (64,1 с).

Границы: backend не подключён как authoritative storage native мира. Эта
команда не реализует присутствие игроков и дедлайн: их проверяет caller/native
adapter перед вызовом. Существующий mechanism защиты активных требований
сохранён; старые story definitions не следует подключать к новым контрактам.
Не является новым live ✅ и не заменяет испытания реальных exe.
