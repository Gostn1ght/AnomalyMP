## Сервер друга: мёртвые кнопки панели и падение «нехватка памяти» (`54b5c43c6`)

- Панель локаций читала `host_view.json`, а watchdog с самого начала пишет
  `host_view_<компьютер>.json` → панель всегда считала управление
  отключённым, все кнопки карт были неактивны. Теперь читается файл своего
  ПК; ошибка скрытого watchdog пишется в `appdata\server\netcoop_cluster\
  watchdog_error.log` и показывается в панели. Если в плане ни один адрес не
  локальный (внешний IP для игры через интернет), все карты считаются своими.
  Проверено настоящим watchdog на временной папке (без запуска серверов):
  панель видит подключение, 4 кнопки активны — для 127.0.0.1 и для внешнего IP.
- Падение выделенного сервера у друга (RTX 5060, `[error][8] Недостаточно
  ресурсов памяти`, адрес по PDB → `dx103DFluidManager.cpp:200`): сервер
  создавал 3D-текстуры объёмного дыма. `o.volumetricfog` теперь ложно при

  выходят сразу. В игре не проверено.

## Падение «Can't find variable level_name in [header]» (`69188e0d5`)

Скриншот друга: выделенный сервер падал при старте в `CInifile::r_string`.
`CApplication::GetArchiveHeader` (вызывается `xrServer::get_map_download_url`
при подключении, в т.ч. собственного клиента сервера) читал `level_name` у
**каждого** архива; архивы Lost Zone (`95_server_*`, `99_lz_patch_*`,
скрипты/оверлей) пишутся `lzpack.make_db` с заголовком без него. У владельца
не проявлялось (его серверы работали без защищённых архивов), у друга раньше
маскировалось падением 3D-дыма. `Level_ID`/`GetArchiveHeader`/список карт
теперь пропускают архивы без `level_name`/`level_ver`; новые архивы lzpack
получают `level_name = lostzone`. Клиент не затронут (там перебираются только
неподгруженные архивы).

## Панель локаций: галочки, прогресс, запуск одной кнопкой (`592cad5ae`)

- Галочки у карт (хостер выбирает, что запускать; `panel_selected.txt`),
  «Запустить отмеченные» сам поднимает watchdog и отдаёт команды; полоса и %
  загрузки по каждой карте и общая полоса как в лаунчере; правый клик — одна карта.
- Watchdog: процент по вехам лога (xrGame → RENDER → мир → spawn registry →
  HOM → раздача NPC → готово; проверено на логе Кордона), состояние «в очереди»
  (в т.ч. для ещё не прочитанной команды), готовность больше не по
  «loading saved world» (пишется в начале загрузки). Ручной запуск больше не
  ждёт бесконечно свободной RAM: стартует, если хватает RAM + файла подкачки;
  иначе панель показывает свободно/нужно ГБ.
- Проверено: watchdog на временной папке с заглушкой exe, клик «Запустить»
  без подключённого управления → watchdog поднят, команды приняты, первая карта
  `loading`, вторая `queued`.
