## Fixed

- **Weather after a reconnect (52ad8dc67).** A pure client has no ALife and
  never runs `restart_all`: its Lua state lives across sessions. The weather
  follower kept the last session's server weather, so the first weather of
  the new session was a slow transition from the level default. It resets at
  every game start. (Emission and psi views already reset with the Actor.)
- **Respawned Actor kept the killer (52ad8dc67).** `character_clear_dead_body_state`
  clears killer and death time ("server entity has a killer and is not dead"
  on every respawn in the owner's log).
- **Seated T-pose (52ad8dc67).** `OnChangeVisual` invalidates the seat motion:
  a seated player whose model changed was left in the bind pose for others.
- **Tasks and dialogues (fd1044d15).** `zz_netcoop_sandbox` (owner 2026-10-09
  story retirement) also blocked every GAMMA task offer and reward, failed
  every task of the player on each update and cut every NPC's dialogues to
  trade/repair with a forced trader start dialogue. Only `xr_effects` story
  task calls stay blocked; story NPCs stay retired. Tasks run per player on
  the server (`server_task_manager`).
- **Inventory: weight only (fd1044d15).** No live cell limit for pickup, loot,
  transfer and purchase; the 512-item save format limit stays. The inventory
  shows GAMMA's weight again (`netcoop_inventory_slots` returns nothing).
  Likely also the player-corpse loot refusals (a full backpack and "take all").
- **Grenades, RG-6, rockets (38a8fd286).**
  - `GE_LAUNCH_ROCKET` carries the server's launch position, direction and
    velocity; clients flew their copy from an identity matrix (the RPG rocket
    was never seen). RPG-7, underbarrel and RG-6 write and read it.
  - RG-6 (Bulldog, M79, ...) had no multiplayer shot. The owner sends it
    (kind 1), the server launches like the RPG-7.
  - Hand grenades: a client never has a fake missile, so a player's throw
    did nothing. The owner sends position, direction and force (kind 3); the
    server spawns its fake missile when needed, throws and arms it, then puts
    the next grenade into the hands. The release carries the throw so other
    clients fly their copy the same way.
