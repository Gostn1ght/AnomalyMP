## Проверенные приёмы (из прошлых сессий)
- На чистом клиенте нет ALife: `alife_create_item/alife_release/give_money/install_upgrade` там ничего не делают.
  Такие действия — через `netcoop_item_action(kind, item, target, action)` → сервер
  `netcoop_server_compat.item_action` (там `db.actor` привязан к игроку). Команды `netcoop_command(...)`
  → `netanomaly_server.on_client_command` — db.actor НЕ привязан, используй entity_id.
- Код UI GAMMA можно выполнять на сервере «без окна» с заглушкой виджетов (см. `server/netcoop_workshop.script`),
  клиент шлёт только выбор (номер рецепта, ячейки дерева).
- Проверки GAMMA «рядом с актором» на сервере меряют до служебного актора — заменяй ближайшим игроком.
- Постоянный ID предмета: `netcoop_item_uid(id)` (сервер), общее хранилище кластера `netcoop_store_read/swap`.
